# 读取图片（透明填充）- DDHT

分类：`DDHT/Image`；节点类型：`DDHT_LoadImage`。

按照 ComfyUI 原版“加载图像 / Load Image”的方式上传、选择和读取图片，增加可选的透明填色功能。直接调用当前安装版本的原版读取器，不维护另一套文件解码实现；格式支持、EXIF 方向、多帧处理、文件有效性检查和文件变更检测均跟随该版本的 ComfyUI。

## 输入

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| image | 原版文件列表 | 使用原版图片选择框和上传按钮，从 ComfyUI 输入目录选择或上传图片 |
| 填充透明区域 | 关闭 | 开启后按 Alpha 将透明区域和半透明边缘合成到指定背景颜色 |
| 填充颜色 | #FFFFFF | 支持 `#RRGGBB` 或 `#RGB`，例如白色 `#FFFFFF`、黑色 `#000000`、绿色 `#00FF00` |

关闭填充时忽略颜色字段，原样传递原版读取器的 IMAGE 和 MASK。开启时，完全透明处变为指定颜色，完全不透明处保留原色，半透明处按透明度混合。例如半透明红色填白色后得到浅红色，不会留下生硬的边缘。

## 输出与预览

- `图片`：ComfyUI 的 IMAGE，保留原版读取器返回的分辨率、批次、设备及浮点类型；开启填充时处理整个批次。
- `透明遮罩`：关闭填充时保留原版 MASK，透明为 1、不透明为 0；开启后全为 0。不带透明信息的图片保留原版全零遮罩约定，包括某些版本使用的 64×64 遮罩。

上传或选择图片时使用 ComfyUI 原生预览；连接到后续节点并运行后，节点预览显示本次实际输出的第一张图片及填色效果。多帧输入仍完整输出，预览只显示第一帧。预览在 ComfyUI 临时目录生成最长边不超过 1024 的缩略图，关闭填充时保留预览透明度，不修改上传的原文件。

此节点与“文件夹图片读取”相互独立：一个手动选择图片，一个按规则从目录抽取图片。无需新增依赖。更新仓库并重启 ComfyUI 后，搜索“读取图片（透明填充）- DDHT”即可添加。

## 验证范围

测试验证原版上传接口和文件检查的委托、颜色格式、完全透明/半透明/不透明混合、多帧与不同尺寸的零遮罩、原输入不被修改、预览像素以及节点注册。数值计算与预览使用 NumPy/Pillow，ComfyUI 和 Torch 接口使用替代对象；尚未在真实 ComfyUI 浏览器和 GPU 环境验证。
