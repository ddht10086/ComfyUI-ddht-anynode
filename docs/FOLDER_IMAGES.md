# 文件夹图片读取 - DDHT

分类：`DDHT/Image`；节点类型：`DDHT_FolderImage`。

每次节点执行从文件夹读取一张图片，输出给下游，并在节点内显示预览。更新仓库后重启 ComfyUI，即可搜索节点名称添加；常见格式无需新增依赖。

## 输入

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| 文件夹路径 | 空 | 填写运行 ComfyUI 的机器上的图片目录，支持中文、空格、带引号路径和环境变量；建议使用绝对路径 |
| 读取方式 | 随机 | 随机播放列表或按文件名顺序循环读取 |
| seed | 0 | 生成新一轮随机列表时使用；当前列表未播完时修改种子不会重排，顺序模式忽略它 |
| 包含子文件夹 | 关闭 | 开启时扫描下级目录，不跟随目录符号链接 |
| 顺序起始索引 | 0 | 顺序模式第一次读取的位置，从 0 计数；超出图片数时取余 |
| 顺序重置标记 | 0 | 改成另一个整数后，下一次从起始索引重新开始 |
| 填充透明区域 | 关闭 | 开启时将透明区域和半透明边缘与指定颜色合成 |
| 填充颜色 | #FFFFFF | 支持 `#RRGGBB` 或 `#RGB`；白色 `#FFFFFF`、黑色 `#000000`、绿色 `#00FF00` |
| 随机重置标记 | 0 | 改成另一个整数后，下一次随机读取会按当时的 seed 从头生成播放列表 |

在其他电脑的浏览器中操作 ComfyUI 时，应填写 ComfyUI 服务器能读取的目录。不会上传文件，也不会修改源图片。

## 随机与顺序

**随机模式现在采用音乐播放器式的随机播放列表。** 旧版每次重新从全部文件中抽一张，固定种子会总选同一张，改变种子也可能再次抽中已经输出的图片。新版先将全部图片索引洗牌，再逐张输出：

1. 首次执行时，用种子打乱完整图片列表。
2. 每次执行读取列表中的下一张，一轮内每个文件恰好输出一次。
3. 全部输出后重新洗牌，开始下一轮；图片数至少为 2 时，新一轮首张不会是上一轮末张。
4. 只有一张图片时，每次输出该图片。

使用独立随机数生成器，不影响采样器或其他节点的随机状态。**固定 seed 也会逐张前进**；同一文件列表、相同种子配置从头开始，可以复现完整播放序列，轮次也参与洗牌。种子旁的 `control_after_generate` 控件可用 `fixed` 保持种子，或用 `randomize` 更新种子：新版只在生成下一轮列表时读取当时的种子，自动更新种子不会打断当前轮。手动改变 seed 想立即生效时，同时改变“随机重置标记”。

列表一旦生成，读取、张量转换、预览失败或中断都不消费当前图片；即使失败后 seed 被自动更新，也会先重试当前项。成功输出后，后续节点失败不会回退播放进度。不同节点实例各自保存列表。去重依据文件路径；同一内容保存为两个不同文件时，仍被视为两张图片。

更换目录、改变扫描范围、文件列表增删改名、改变随机重置标记，或成功执行顺序读取后切回随机，会从第 0 轮重建列表；重建后可能重新遇到旧列表已播放的图片。修改透明填色设置、顺序起始索引或顺序重置标记不会打断随机列表。仅替换同名文件的内容时保留播放进度。

**顺序模式**按相对文件名自然排序，不区分英文大小写；例如 `1.png → 2.png → 10.png → 1.png`。每次节点成功读取并生成预览后前进一张；读取或预览失败不前进。不同节点实例各自计数，后续节点失败不会回退本节点已经完成的读取。

顺序模式更换目录、修改起始索引/顺序重置标记、切换扫描范围、文件列表增删改名，或成功执行随机读取后切回顺序时，从起始索引重新开始。

随机列表和顺序进度均保存在当前 ComfyUI 节点实例中。重启 ComfyUI、重建节点或清除节点对象缓存会重置进度；禁用对象缓存的运行方式不保留播放进度。播放列表仅保存文件索引，不会预先将整个文件夹的图片载入内存。

旧工作流的“随机”选项会直接使用新行为，原控件顺序和输出连接保持兼容；新增的“随机重置标记”位于末尾且默认为 0，无需重建节点。

每次执行都会重新扫描目录并读取文件，避免复用上一次图片缓存；替换同名文件后也会读取新内容。目录为空、路径错误、所选图片损坏或缺少解码器时会明确报错，不会悄悄换成其他图片。

## 格式与透明区域

支持 JPG/JPEG/JFIF、PNG/APNG、WebP、BMP/DIB、GIF、TIFF、ICO、TGA、PPM/PGM/PBM/PNM、PCX、DDS 和 JPEG 2000 等 Pillow 可解码的格式。扩展名不区分大小写。AVIF 需要当前 Pillow 带 AVIF 支持，旧环境可安装 `pillow-avif-plugin`；HEIC/HEIF 需要在 ComfyUI 的 Python 环境安装 `pillow-heif`。不同环境的编译选项可能影响部分格式，详见 [Pillow 格式文档](https://pillow.readthedocs.io/en/stable/handbook/image-file-formats.html)。

GIF、动态 WebP/APNG、多页 TIFF 等每次只取第一帧/第一页。应用 EXIF 方向，支持调色板透明、灰度透明和 CMYK 转 RGB；16 位灰度 PNG/TIFF 会归一化到 0～1，避免中间灰度变成纯白。

- **关闭填充**：`IMAGE` 输出 RGB，透明信息单独输出为 `MASK`，与 ComfyUI 的常用约定一致：完全透明为 1，完全不透明为 0。下游需要同时使用遮罩才能保留透明效果；仅连接 IMAGE 不会自动传递 Alpha。
- **开启填充**：按 Alpha 与填充颜色合成 RGB，半透明边缘也会混合；输出遮罩为全 0。该选项也适用于 WebP 等带透明度的格式。

## 输出与预览

| 输出 | 内容 |
| --- | --- |
| 图片 | 一张原尺寸 RGB 图片，`IMAGE [1,H,W,3]`，float32、0～1 |
| 透明遮罩 | `MASK [1,H,W]`，填色后或无透明区域时全 0 |
| 文件名 | 所选图片的文件名，包含扩展名 |
| 完整路径 | 所选图片的绝对路径 |
| 图片索引 | 在当前文件名自然排序列表中的位置，从 0 开始；不是随机播放列表中的播放进度 |
| 图片总数 | 当前目录及选定扫描范围内的图片候选数 |

预览使用 ComfyUI 自带的图片显示功能，无需单独连接预览节点，也能单独执行本节点。临时目录中生成最长边不超过 1024 的 PNG 缩略图；下游图片保持原尺寸。预览反映当前填色效果，关闭填色时保留 Alpha。源图和永久输出目录均不写入副本，临时预览由 ComfyUI 临时目录管理。

典型连接：`文件夹图片读取 → 局域网 LLM / DeepSeek API / 图片处理节点`。
